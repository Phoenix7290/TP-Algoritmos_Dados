Vértice

Elemento atômico do grafo que representa uma entidade. Na lista de adjacência é uma chave do dicionário adj; na matriz é uma chave do dicionário index mapeada para um índice inteiro.

# lista de adjacência

self.adj: dict[str, set] = {}   # cada chave é um vértice

# matriz de adjacência

self.index: dict[str, int] = {} # cada chave é um vértice → índice
Exemplo concreto: vértice "A" → adj["A"] = {"B","C"} / index["A"] = 0
Aresta
Par ordenado (u, v) que indica conexão entre dois vértices. Em grafo não-dirigido, a aresta {u,v} é armazenada nos dois sentidos.

# lista: aresta A–B aparece em dois lugares

adj["A"].add("B")   # A→B
adj["B"].add("A")   # B→A  (simetria)

# matriz: aresta A–B aparece em duas células

mat[0][1] = 1       # A→B
mat[1][0] = 1       # B→A  (simetria)
Exemplo concreto: aresta H–I → adj["H"]∋"I", adj["I"]∋"H" / mat[7][8]=1, mat[8][7]=1

Lista de adjacência

Estrutura que associa cada vértice ao conjunto de seus vizinhos. Custo de memória O(V+E); eficiente para grafos esparsos e para iterar vizinhos.

self.adj: dict[str, set] = {
    "A": {"B","C"},  "B": {"A","D","E"},
    "H": {"D","E","I"}, ...
}

Consulta de adjacência: "B" in adj["A"] → O(1) amortizado (conjunto hash), mas depende do grau de u.

Matriz de adjacência

Matriz V×V onde mat[i][j]=1 se existe aresta (u,v) e 0 caso contrário. Custo de memória O(V²); acesso has_edge em O(1) por indexação direta.
self.mat: list[list[int]]

# mat[index[u]][index[v]] == 1  ↔  aresta (u,v) existe
