Exercício 9: Comparação (Build-Heap vs. Inserção Incremental)Este exercício destaca a diferença entre a abordagem "Top-Down" (inserções) e "Bottom-Up" (Build-Heap).Comparação PráticaCritérioInserção IncrementalBuild-Heap (Otimizado)AbordagemComeça com heap vazia e insere um por um.Organiza um array pronto de baixo para cima.Operação Basesift-up (subir o elemento).sift-down (descer o elemento).Complexidade$O(n \log n)$$O(n)$Nº de TrocasMaior (elementos na base viajam mais).Menor (mais elementos fazem trocas curtas).Discussão dos ResultadosAo inserir um elemento por vez, cada nova folha pode ter que subir até a raiz ($\log n$). Como existem muitos nós folha ($n/2$), o custo total é alto. No build_heap, os muitos nós folha não fazem nada (já são heaps de um elemento), e apenas os níveis superiores fazem trocas. Como há poucos nós nos níveis superiores, o custo total cai para linear.Conclusão: Para criar uma heap do zero a partir de dados existentes, o build_heap é sempre preferível. A inserção incremental só deve ser usada se os dados chegarem em tempo real (um a um).
